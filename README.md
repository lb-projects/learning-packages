# learning-packages

SCORM-1.2-Lernpakete für Lernplattformen.

| Paket | Inhalt |
|---|---|
| [kNN algorithm](kNN%20algorithm/README.md) | Interaktiver Simulator zum Klassifikationsverfahren k nächste Nachbarn (kNN) |
