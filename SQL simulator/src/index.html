Datenbank laden

Wählen Sie eine vorbereitete Beispieldatenbank oder laden Sie eine eigene SQL-Datei hoch. Die Datenbank liegt nur in Ihrem Browser; nach dem Neuladen der Seite ist sie wieder weg.

Beispieldatenbanken

Eigene SQL-Datei hochladen

Erlaubt: .sql oder .txt (höchstens 1 MB, am besten im Zeichensatz UTF-8) mit den Befehlen DROP TABLE, CREATE TABLE (auch mit CHECK-Bedingungen), INSERT INTO (auch INSERT INTO … SELECT mit WITH) sowie CREATE VIEW. Exporte aus phpMyAdmin werden ebenfalls verstanden. Grenzen: 50 Tabellen, 50 Spalten je Tabelle, 20.000 Datensätze, Texte bis 1.000 Zeichen. Die Datei ersetzt die aktuelle Datenbank – auch Änderungen von Seite 3.

Tabellen

Hier sehen Sie den Aufbau und den Inhalt aller Tabellen der geladenen Datenbank. PK kennzeichnet den Primärschlüssel, FK einen Fremdschlüssel mit der Spalte, auf die er verweist. Je Tabelle sind etwa fünf Datensätze sichtbar; weitere erreichen Sie durch Scrollen innerhalb der Tabelle. Unter jeder Tabelle lässt sich der CREATE TABLE-Befehl aufklappen, der die Tabelle erzeugt. Sichten (Views) stehen mit ihrem aktuellen Ergebnis in einem eigenen Abschnitt darunter.

SQL-Befehle

Geben Sie einen SQL-Befehl ein und klicken Sie auf „Ausführen“ (oder drücken Sie Strg + Enter). Erlaubt sind SELECT (auch mit WITH), INSERT, UPDATE und DELETE sowie CREATE VIEW und DROP VIEW. Mehrere Befehle werden durch ; getrennt und gemeinsam ausgeführt: Enthält einer einen Fehler, bleibt die Datenbank unverändert.

Kurzreferenz: unterstützte SQL-Befehle

Abfragen

SELECT [DISTINCT] Spalte1, Spalte2 AS Name, COUNT(*) …
FROM tabelle t
  [INNER | LEFT | RIGHT] JOIN andere a ON a.t_id = t.id
WHERE Bedingung
GROUP BY Spalte
HAVING Bedingung mit Aggregatfunktion
ORDER BY Spalte [ASC | DESC]
LIMIT Anzahl [OFFSET Start];
  • Bedingungen: = <> < <= > >=, AND, OR, NOT, BETWEEN … AND …, LIKE 'M%' (% beliebig viele Zeichen, _ genau ein Zeichen), IN (…), IS NULL, IS NOT NULL, EXISTS (SELECT …)
  • Aggregatfunktionen: COUNT(*), COUNT(Spalte), COUNT(DISTINCT Spalte), SUM, AVG, MIN, MAX; dazu ROUND(Zahl, Stellen)
  • Rechnen: + - * / %, Klammern
  • Aliase: FROM schule s bzw. FROM schule AS s, danach s.Adresse; Spalten: COUNT(*) AS Anzahl
  • Verknüpfungen: JOIN … ON …, LEFT JOIN, RIGHT JOIN, CROSS JOIN oder FROM a, b WHERE a.id = b.a_id
  • Unterabfragen: WHERE Preis > (SELECT AVG(Preis) FROM artikel), WHERE id IN (SELECT …), FROM (SELECT …) AS t
  • WITH: WITH teuer AS (SELECT * FROM artikel WHERE Preis > 50) SELECT Bezeichnung FROM teuer; mehrere Abfragen durch Komma getrennt, auch mit Spaltenliste WITH t (a, b) AS (…)
  • Texte stehen in einfachen Anführungszeichen: 'Müller'; Datumswerte als Text: '2024-03-15'; Dezimalzahlen mit Punkt: 3.50

Daten ändern

INSERT INTO tabelle (Spalte1, Spalte2) VALUES (1, 'Text'), (2, 'Noch ein Text');
UPDATE tabelle SET Spalte2 = 'Neu' WHERE Spalte1 = 1;
DELETE FROM tabelle WHERE Spalte1 = 2;
INSERT INTO tabelle (Spalte1, Spalte2) SELECT id + 100, Name FROM andere;

Sichten (Views)

CREATE VIEW teure_artikel AS SELECT Bezeichnung, Preis FROM artikel WHERE Preis > 50;
CREATE OR REPLACE VIEW teure_artikel AS SELECT …;
DROP VIEW teure_artikel;

Eine Sicht ist eine gespeicherte Abfrage: SELECT * FROM teure_artikel zeigt immer den aktuellen Stand der Tabellen. In Sichten kann nicht geschrieben werden.

  • Groß- und Kleinschreibung: Tabellen- und Spaltennamen müssen genau so geschrieben werden wie auf Seite 2 (Preis, nicht preis). Auch beim Vergleich von Texten zählt sie: 'Berlin' ist nicht 'berlin'. SQL-Schlüsselwörter schreibt man üblicherweise groß (SELECT, FROM).
  • Hinweise: Stehen mehrere Tabellen in FROM, aber nicht alle sind über eine Bedingung verknüpft, erscheint ein Hinweis auf das kartesische Produkt. Ist es beabsichtigt, schreiben Sie CROSS JOIN.

„Datenbank zurücksetzen“ stellt den Stand nach dem Laden wieder her.
