Graph eingeben

Ein Graph besteht aus Knoten und Kanten. Laden Sie eine Datei oder einen Beispielgraphen, oder geben Sie Knoten und Kanten einzeln ein. Der Graph wird sofort gezeichnet; Änderungen wirken auf alle anderen Seiten.

Graph laden

Erlaubt: .csv, .xlsx oder .ods (höchstens 2 MB) als Kantenliste oder Adjazenzmatrix. Die Datei ersetzt den vorhandenen Graphen.

Dateiformat

Kantenliste: je Zeile von;nach;Gewicht, z. B. A;B;4. Das Gewicht ist freiwillig (Standard 1). Eine Zeile mit nur einem Namen legt einen Knoten ohne Kante an. Eine Kopfzeile wie von;nach;gewicht ist erlaubt. Eine Zeile mit nur gerichtet oder ungerichtet legt die Art des Graphen fest; fehlt sie, gilt die Einstellung auf dieser Seite.

Adjazenzmatrix: erste Zeile mit leerer Ecke (oder gerichtet/ungerichtet) und den Knotennamen, darunter je Knoten eine Zeile mit Namen und Gewichten. Leere Zelle, - oder x bedeuten „keine Kante“; 0 ist eine Kante mit Gewicht 0. Ausnahme: Besteht die Matrix nur aus 0 und 1 (ungewichtete Adjazenzmatrix), bedeutet 0 „keine Kante“, ebenso 0 auf der Hauptdiagonalen. Ohne Angabe gilt eine symmetrische Matrix als ungerichtet, sonst als gerichtet.

Knotennamen: höchstens 12 Zeichen (Buchstaben, Ziffern, _, -). Gewichte: ganze Zahlen von −999 bis 999. Höchstens 26 Knoten und 150 Kanten. CSV-Trennzeichen: Semikolon, Komma oder Tabulator.

    Adjazenzlisten

      Breitensuche

      Die Breitensuche (BFS) besucht vom Startknoten aus zuerst alle direkten Nachbarn, dann deren Nachbarn usw. Entdeckte Knoten warten in einer Warteschlange (wer zuerst kommt, wird zuerst besucht). Gewichte spielen keine Rolle; der Abstand zählt die Kanten. Nachbarn werden alphabetisch abgearbeitet.

      Tiefensuche

      Die Tiefensuche (DFS) geht vom Startknoten aus so weit wie möglich in die Tiefe: Sie ruft sich für den ersten noch nicht besuchten Nachbarn selbst auf (Rekursion). Gibt es keinen solchen Nachbarn mehr, kehrt sie zum aufrufenden Knoten zurück. Der Aufrufstapel zeigt, welche Aufrufe noch laufen. Gewichte spielen keine Rolle; Nachbarn werden alphabetisch abgearbeitet.

      Dijkstra

      Der Dijkstra-Algorithmus berechnet die kürzesten Wege vom Startknoten zu allen anderen Knoten. Er nimmt immer den Knoten mit der kleinsten Distanz aus der Warteschlange; dieser ist dann fertig. Danach prüft er dessen Kanten: Wird ein Knoten so erstmals erreicht oder auf kürzerem Weg, erhält er eine neue Distanz und einen neuen Vorgänger. Jeder Knoten steht als Tripel (Knoten, Vorgänger, Distanz zum Startknoten) in der Tabelle.

      Training

      Hier führen Sie einen Algorithmus selbst aus. Breiten- und Tiefensuche: Klicken Sie die Knoten in der richtigen Reihenfolge an – der erste Klick besucht einen Knoten, der zweite schließt ihn ab. Dijkstra: Füllen Sie die Berechnungstabelle Zeile für Zeile aus und lassen Sie jede Zeile prüfen. Gezählt werden die richtigen Schritte und die Fehlentscheidungen; der Stand wird gespeichert.
